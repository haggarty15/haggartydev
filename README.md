# haggartydev

Personal portfolio site for [haggarty.dev](https://haggarty.dev) — a sleek one-stop shop for recruiters and the public to find out who I am as a developer and what I've been building.

## Pages

- **`index.html`** — Homepage with bio, skills, experience and CV summary
- **`projects.html`** — Projects listing with status, description and next steps
- **`styles.css`** — Shared dark-theme stylesheet

## Deploying

This is a fully static site — no build step required.  
Point your domain / web host at the repo root and serve `index.html`.

For GitHub Pages:  
`Settings → Pages → Source: Deploy from branch → main / (root)`
